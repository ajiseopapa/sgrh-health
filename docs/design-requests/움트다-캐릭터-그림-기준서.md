# 움트다 캐릭터 그림 기준서

2026-11-20 · 정한 사람: TK · 판 4

이 문서는 **어떤 작업을 하더라도 바뀌지 않는 기준**입니다.
앞으로 보내는 모든 요청서는 이 기준 위에서만 씁니다.

- 요청서와 이 기준서가 다르면 **기준서가 맞습니다.**
- 기준서는 TK만 고칩니다. 고칠 때는 판 번호를 올리고, 바뀐 줄을 맨 아래 "고친 기록"에 남깁니다.
- 디자이너는 기준을 바꾸고 싶으면 **그리기 전에 묻습니다.** 그려서 보낸 뒤에 알리는 것은 허락이 아닙니다.

## 1. 기준 캐릭터 (고정)

**2026-11-20부터 기준 머리는 새 유니폼(`uniform-512`)의 머리입니다.** (판 3, TK 결정)

| | 남 | 여 |
| --- | --- | --- |
| 기준 머리 파일 | `head-m-2026-11-20.png` | `head-f-2026-11-20.png` |
| 위치 | `design/` (앱 작업 폴더) | 같음 |
| 크기 | 512×768 (0~364행만 그림, 나머지 투명) | 같음 |
| 뽑은 곳 | 새 간호복 남 | 새 간호복 여 |

- 새 유니폼 10장은 모두 0~364행이 이 기준 머리와 똑같습니다(2026-11-20 대조).
- 새 머리로 그린 기본 운동복 남녀 2장이 승인되면, 그 2장이 **기준 캐릭터**가 됩니다. 그 뒤로는 그 2장을 바탕으로 그립니다.
- 옛 기준 캐릭터(`char-<m|f>-workout.png`, 2026-11-20 이전)는 더 이상 기준이 아닙니다.

### 바뀌면 안 되는 것

- **머리:** 0~364행(목 위)은 기준 머리와 **픽셀까지 같아야** 합니다. 머리카락·얼굴·귀·포니테일이 모두 포함됩니다.
  - 여자 포니테일은 365행 아래로 이어집니다. 이 부분도 새 유니폼 여자 그림과 같은 모양으로 그립니다.
  - 예외는 머리에 쓰는 것뿐입니다. 꾸미기(모자·머리 장식·안경·얼굴 꾸미기·특별)와 조리복의 조리모가 여기에 해당합니다. 이때도 물건에 가려지는 부분만 바뀌고, 눈·입·볼의 위치와 모양은 그대로여야 합니다.
- **발:** 발바닥 마지막 줄은 **y=755**입니다. 모든 그림에서 같습니다.
- **키와 몸:** 키, 어깨 폭, 몸 비율은 기준과 같습니다.
- **자세:** 팔을 내린 차렷 자세입니다. 팔의 각도와 위치는 바꾸지 않습니다.
  - 물건을 들 때도 팔은 그대로 두고, 손 모양만 바꿉니다.

## 2. 그림체 (고정)

- 기준 캐릭터와 같은 도트 그림체로 그립니다. 바깥선은 같은 굵기의 검은 도트 선입니다.
- 배경, 그림자, 후광, 흰 테두리는 넣지 않습니다.
- 색감은 라임·크림·짙은 회색이 중심입니다. 2026-11-20에 받은 꾸미기 아이콘 34장이 색감 기준입니다.

## 3. 파일 규격 (고정)

| 종류 | 크기 | 배치 | 이름 |
| --- | --- | --- | --- |
| 전신 그림 | 512×768 투명 PNG | 기준 캐릭터와 같은 자리(원점 0,0) | `look-<칸>-<키>-<m\|f>.png` |
| 아이콘 | 256×256 투명 PNG | 사방 16px 여백, 긴 쪽 224px, 가운데 | `icon-<칸>-<키>.png` |

- `<칸>`과 `<키>`는 아래 4절 목록에 있는 것만 씁니다.
- 파일은 한 폴더에 모아서 보냅니다. 분류 폴더를 따로 만들지 않습니다.

## 5. 승인된 그림은 다시 그리지 않음

아래 그림은 승인되어 앱에 들어가 있습니다. **요청서에 다시 그려 달라고 적힌 그림만** 새로 그립니다.
머리 경계 정리처럼 작은 손질이라도 마음대로 하지 않습니다. 고칠 곳이 보이면 먼저 알려 주세요.

## 5-1. 고칠 때는 받은 파일 위에서 고침

- 수정 요청을 받으면 **지난번 납품 파일을 열어 그 위에서** 고칩니다. 그림을 처음부터 새로 생성하지 않습니다.
- 요청서에 적힌 곳만 고치고, 나머지 픽셀은 그대로 둡니다.
- 이유: 새로 생성하면 매번 얼굴, 몸, 옷이 조금씩 달라져서 이미 맞춘 것이 다시 깨집니다. 2026-11-20 하루에만 이 일이 여러 번 생겼습니다.

## 5-2. 받은 그림 자동 검수 (2026-11-23)

납품 폴더를 받으면 먼저 검수 스크립트를 돌립니다. 아래 6가지를 장마다 확인합니다.

- 파일 이름
- 크기 512×768
- 반투명 0
- 발 y=755
- 머리 0~364행
- 떠 있는 점

```powershell
cd E:\claude\.worktrees\sgrh-health-v21
python scripts\check-delivery.py "<납품 폴더>"
```

- 결과는 납품 폴더 안에 생깁니다.
  - `_검수결과.md`: 장마다 통과/불통과와 이유
  - `_검수모음.png`: 전체 모음, 불통과는 빨간 테두리
- 번짐, 디자인, 사원증은 스크립트가 못 봅니다. 모음 그림을 눈으로 확인합니다.
