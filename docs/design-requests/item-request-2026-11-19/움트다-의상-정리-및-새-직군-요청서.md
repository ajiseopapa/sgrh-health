## 요청 1 — 의상 레이어 가장자리 정리 (꼭 필요)

앱에 넣어 보니 의상 그림의 가장자리가 지저분해 보입니다. 특히 여성형이 심합니다. `outfit-fix-01-problems.png`를 봐 주세요.

| 의상 | 문제 |
| --- | --- |
| 여성 스크럽 | 오른팔과 소매가 뜯긴 것처럼 끊김 |
| 여성 간호복 | 소매 끝이 거침. 목 주변에 잔선 |
| 여성 정장 | 치마 옆에 라임색 점이 보임(기본 반팔이 비침) |
| 여성 셔츠 차림, 남성 셔츠 차림 | 어깨 밖으로 잔선. 목 주변 점 (이 의상은 빠지지만 같은 문제가 다른 데에도 생기지 않게 참고해 주세요) |
| 여성 가운과 안경 | 바지에 검은 얼룩 (이 의상은 빠짐) |

### 원인

의상 상의가 기본 반팔보다 작거나 모양이 달라서, **기본 반팔의 검은 외곽선이 소매·어깨 밖으로 삐져나옵니다.** 또 의상을 시트에서 잘라 오면서 가장자리 일부가 깨졌습니다.

앱에서 기본 반팔을 빼고 그려 보기도 했는데, 그러면 소매 아래 외곽선까지 사라져 더 어색해졌습니다. 그림에서 정리해 주셔야 합니다.

### 정리 방법

1. 기본 몸 6장을 겹친 위에 의상 레이어를 올립니다(앱과 같은 순서).
2. 의상 상의는 **기본 반팔을 완전히 덮도록** 그립니다. 소매 길이·어깨 폭이 기본 반팔보다 작으면, 그 차이만큼 반팔이 보이지 않게 의상 쪽을 넓혀 주세요.
3. 의상의 바깥 가장자리에 **끊기지 않는 검은 외곽선**을 둘러 주세요. 기본 캐릭터와 같은 굵기입니다.
4. 떨어진 점, 잔선, 반쯤 투명한 얼룩을 지워 주세요.

### 다시 받을 파일 (5벌 × 남녀)

| 파일 | 내용 |
| --- | --- |
| `outfit-top-<의상>-<m\|f>.png` | 상의 |
| `outfit-bottom-<의상>-<m\|f>.png` | 하의 |
| `outfit-shoes-<의상>-<m\|f>.png` | 신발 |
| `char-<m\|f>-<의상>.png` | 위 레이어를 겹친 전신 그림 |

- `<의상>`: `nurse`, `doctor`, `office`, `hoodie`, `scrub`
- 하의·신발이 문제없으면 상의만 주셔도 됩니다. 그때는 전신 그림만 같이 다시 주세요.

## 요청 2 — 새 직군 복장 2벌 (꼭 필요)

병원의 다른 직군도 자기 옷을 고를 수 있게 2벌을 추가합니다.

| 의상 | 키 | 누구 | 모습 |
| --- | --- | --- | --- |
| 조리복 | `chef` | 영양팀 | 흰 조리복(더블 단추), 검은 또는 체크 바지, 검은 조리화. 조리모 |
| 작업복 | `worker` | 시설·환경팀 | 작업 점퍼(남색 또는 회색), 같은 색 작업 바지, 작업화. 반사띠나 주머니 |

- 다른 의상처럼 **왼쪽 가슴에 사원증**을 달아 주세요. 운동복만 사원증이 없습니다.
- 간호복·가운·스크럽과 **한눈에 구분되는 색**이면 좋겠습니다. 흰 조리복은 가운과 헷갈리지 않게 조리모와 더블 단추로 구분해 주세요.
- 색은 앱 색(라임 `#D8F36A`, 차콜 외곽선)과 어울리게 부탁드립니다.

### 받을 파일 (2벌 × 남녀)

| 파일 | 내용 |
| --- | --- |
| `outfit-top-<chef\|worker>-<m\|f>.png` | 상의 |
| `outfit-bottom-<chef\|worker>-<m\|f>.png` | 하의 |
| `outfit-shoes-<chef\|worker>-<m\|f>.png` | 신발 |
| `outfit-hat-chef-<m\|f>.png` | **조리모** (조리복만). 아래 설명 참고 |
| `char-<m\|f>-<chef\|worker>.png` | 위 레이어를 겹친 전신 그림 |
| `icon-outfit-<chef\|worker>.png` | 의상 고르기 칸에 쓸 작은 그림이 필요하면 (선택) |

### 조리모

조리모는 모자 칸(`hat`) 그림과 같은 규칙으로 그려 주세요. 머리 윗부분을 덮어 머리카락이 모자 위로 삐져나오지 않게요. 앱에서는 이렇게 씁니다.

- 조리복을 입고 모자 아이템이 없으면 조리모를 씌웁니다.
- 모자 아이템을 쓰면 조리모 대신 그 모자를 보여 줍니다.

## 공통 규격 (v5와 같음)

- 캔버스 512×768, 투명 PNG, 기본 몸과 같은 자리(원점 0,0에 겹침).
- 기본 몸 6장(v5 `base/`)은 그대로 씁니다. 다시 주지 않으셔도 됩니다.
- 겹치는 순서: 가방 → 뒷머리 → 몸 → 기본 신발 → 의상 신발 → 기본 하의 → 의상 하의 → 기본 상의 → 의상 상의 → 안경 → 앞머리 → 머리 장식 → 모자 → 소품 → 특별.
- 아이템 47종이 새 의상 위에서도 자연스러워야 합니다. 특히 상의·하의·신발 아이템은 의상의 같은 부위를 대신합니다.
- 편집 원본(.ora 등)도 같이 주세요.

## 확인 방법

보내 주시기 전에 아래를 확인해 주세요.

- [ ] 기본 몸 6장 + 의상 레이어를 겹쳤을 때, 의상 밖으로 기본 반팔의 외곽선이나 라임색이 한 점도 보이지 않는가
- [ ] 의상 바깥 가장자리에 외곽선이 끊긴 곳이 없는가
- [ ] 떨어진 점·잔선·반투명 얼룩이 없는가
- [ ] 겹친 결과가 `char-<m|f>-<의상>.png`와 같은가
- [ ] 휴대폰 크기(128×192, 48×72)로 줄였을 때 조리복·작업복이 다른 의상과 바로 구분되는가
- [ ] 조리모 위로 머리카락이 삐져나오지 않는가
- [ ] 사원증이 운동복을 뺀 모든 의상에 있는가
