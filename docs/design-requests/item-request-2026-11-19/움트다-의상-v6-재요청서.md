검수 수치(중간 알파 0, 떨어진 조각 0)는 통과했지만, **의상 안쪽에 남은 조각과 덧댄 자국**은 그 수치로 잡히지 않습니다.

파일 이름, 캔버스(512×768, 원점 0,0), 겹치는 순서, 조리모 규칙은 **v6와 같습니다.** 바꾸지 마세요.

## 무엇이 깨졌나 (`outfit-v6-problems.png`)

| 부위 | 보이는 문제 |
| --- | --- |
| 가운(남·여) | 몸판에 **다른 결의 네모 조각이 덧대어진 자국**, 소매 끝 검은 자국·끊김, 여성 오른팔 옆 흰 덩어리 |
| 정장(남·여) | 팔이 **어두운 네모 덩어리**로 덮임. 팔 모양이 사라짐. 여성은 손 옆에 조각 |
| 스크럽(여) | 오른팔 쪽에 **회색 얼룩·살색 조각**이 그대로 남음 |
| 간호복(여) | 목·어깨에 가는 잔선 |
| 후드 집업(여) | 소매 외곽이 끊기고 몸판에 덧댄 자국 |
| 조리모 | 선이 가늘고 매끈한 벡터 선이라 **도트 캐릭터와 화풍이 다름** |
| 작업복(여) | 바지 옆선과 신발이 깨짐 |
| 전체 | 새로 두른 외곽선이 **가늘고 매끈한 곡선**이라 머리·얼굴·손의 굵은 도트 외곽선과 따로 놀음 |

## 원인으로 보이는 것

- 시트에서 잘라 온 조각을 이어 붙이고, 그 위에 외곽선을 자동으로 두른 것으로 보입니다.
  그래서 바깥 테두리는 깨끗해졌지만 **안쪽에 남은 팔·손·옷 조각과 덧댄 네모**가 그대로 보입니다.
- 정장은 반팔을 덮으려고 팔 전체를 네모로 칠한 것으로 보입니다.

## 다시 그리는 방법

1. **상의는 조각을 붙이지 말고 한 벌을 처음부터 도트로 그려 주세요.** v5 기본 몸 6장을 겹친 위에서, 512×768 원본 해상도로 그립니다.
2. 외곽선은 **기본 캐릭터 머리·얼굴·손과 같은 굵기와 같은 계단식 도트 선**으로 그려 주세요. 매끈한 곡선이나 가는 선은 쓰지 않습니다.
3. 소매는 **팔 모양을 따라** 그립니다. 반팔 외곽선을 덮어야 해서 소매가 커지는 것은 괜찮지만, 팔 전체를 네모로 덮지 마세요.
4. 옷 안쪽은 **한 가지 결(질감)** 로 칠합니다. 다른 결의 네모 조각, 이전 그림의 손·팔 조각, 회색·살색 얼룩이 남지 않게 해 주세요.
5. 조리모도 같은 도트 선과 같은 굵기로 다시 그려 주세요. 모양과 크기는 v6 그대로 좋습니다.
6. 하의·신발은 v5 그대로 써도 됩니다. **여성 작업복 하의·신발만** 다시 그려 주세요.

## 아이템(v5) 상의·하의도 같이 다시 (추가 요청)

앱에 넣고 보니 **아이템 중 상의·하의도 같은 문제**가 있습니다. 모자·머리 장식·안경·소품·특별 아이템은 괜찮습니다.
`item-v5-problems-m.png`, `item-v5-problems-f.png`(왼쪽 = 앱에서 실제로 보이는 모습)를 봐 주세요. 전체 모습은 `item-v5-all-m.png`, `item-v5-all-f.png`입니다.

| 아이템 | 보이는 문제 |
| --- | --- |
| 조끼, 흰 집업, 크림 후드, 검은 점퍼, 흰 바람막이 | 외곽선이 톱니처럼 들쭉날쭉, 소매 끝·손 옆에 조각, 크림 후드 밑단이 뜯긴 모양 |
| 초록 후드 | 어깨 외곽 끊김 |
| 회색 반바지, 검은 반바지, 짧은 반바지 | 다리 옆에 라임색·흰 조각, 외곽선 끊김 |
| 회색 긴바지 | 외곽선이 군데군데 비고 안쪽 결이 지저분함 |
| 줄무늬 바지 | 옆선 라임 줄 끝이 깨짐 |

앱에서 기본 반팔·기본 바지를 빼고도 겹쳐 봤는데(오른쪽) 똑같이 지저분합니다. 그림 자체를 정리해 주셔야 합니다.
위 "다시 그리는 방법" 1~4번과 같은 방법(조각 없이 한 벌씩, 몸과 같은 굵기의 도트 외곽선, 안쪽은 한 결)으로 부탁드립니다.

받을 파일: `item/item-top-<이름>-<m|f>.png` 6종 × 남녀, `item/item-bottom-<이름>-<m|f>.png` 5종 × 남녀 (v5와 같은 이름). 아이콘은 그대로 써도 됩니다.

## 보내기 전 확인 (눈으로)

수치 검사에 더해 **눈으로 하는 확인**을 꼭 해 주세요. 이번에는 수치는 통과했는데 눈으로는 깨져 보였습니다.

- [ ] 전신 그림 14장을 **2배로 확대(최근접 확대)** 해서 상의 안쪽에 조각·얼룩·덧댄 네모가 없는가
- [ ] 소매에 **팔 모양**이 살아 있는가 (특히 정장)
- [ ] 옷 외곽선이 머리·얼굴·손 외곽선과 **같은 굵기의 도트 선**인가
- [ ] 반팔의 라임색·검은 외곽선이 의상 밖으로 한 점도 안 보이는가
- [ ] 휴대폰 크기(128×192)에서도 소매 끝·어깨가 깔끔한가
- [ ] 비교 그림: v5 / v6 / 이번 것을 같은 크기로 나란히 놓은 그림을 같이 주세요
