# 움트다 캐릭터 아이템 재요청서

## 한눈에 보기

보내 주신 두 묶음을 앱에 넣어 확인했습니다. **두 묶음 모두 아직 앱에 넣을 수 없습니다.** 이유는 하나입니다. 아이템이 캐릭터 몸의 제자리에 맞춰 그려지지 않았습니다.

| 받은 묶음 | 좋은 점 | 문제 |
| --- | --- | --- |
| 착용 그림 16종 (`redraw-16-worn-review`) | 입은 모습이 자연스럽고 예쁨. **이번 재요청의 정답지로 씁니다** | 겹칠 수 있는 그림이 아님. 그림마다 캐릭터 크기가 다름 |
| 레이어 납품본 (`umtuda-character-items`) | 파일 이름, 캔버스 크기(512×768), 투명 배경이 맞음 | 아이템을 몸에 맞게 그리지 않고 아이콘을 붙여 둠 |

**요청은 한 가지입니다.** 착용 그림 16종에서 보이는 모습 그대로, 아이템만 따로 떼어 낸 투명 레이어를 다시 만들어 주세요.

## 무엇이 문제였는가

### 1. 레이어 납품본: 아이템이 몸에 맞지 않음

`rework-04-hoodie-good-vs-bad.png`를 봐 주세요. 왼쪽이 착용 그림(맞는 모습), 오른쪽이 레이어를 겹친 결과입니다.

- 후드가 몸에 입혀지지 않고, 작은 후드 그림이 가슴 앞에 떠 있습니다.
- 원래 반팔과 팔이 그대로 보입니다.
- 오른쪽에 다른 그림 조각(손)이 잘려 들어가 있습니다.

다른 아이템도 같습니다(`rework-02-layer-problems.png`).

| 아이템 | 문제 |
| --- | --- |
| 흰 집업, 초록 후드, 크림 후드 | 옷이 몸을 덮지 않고 아이콘이 가슴 앞에 붙어 있음 |
| 진한 운동화 | 발이 아니라 다리 옆에 신발 그림이 놓여 있음 |
| 줄무늬 긴바지, 회색 반바지 | 원래 바지가 밖으로 보임 |
| 야구모자, 밀짚모자 | 머리에 씌워지지 않고 위에 얹혀 있음. 머리카락이 모자 밖으로 나옴 |
| 선글라스 | 눈 위치가 맞지 않고 반투명함 |
| 물병 | 캔버스 오른쪽 끝에 잘려 있음 |
| 왕관 | 머리 위가 아니라 옆에 작게 붙어 있음 |
| 배낭 | 등이 아니라 몸 앞을 가림 |

### 2. 기본 몸 12장: 조금 어긋남

`rework-03-base-compare.png`를 봐 주세요. 받은 기본 몸 6장을 겹친 모습(왼쪽)과 지금 앱의 캐릭터(오른쪽)입니다.

- 팔과 손에 외곽선이 없고 색이 흐립니다.
- 얼굴과 몸 크기가 지금 캐릭터와 조금 다릅니다.

### 3. 착용 그림 16종: 겹칠 수 없음

모습은 좋지만(`rework-01-worn-good-example.png`), 그림마다 캐릭터 크기와 위치가 다르고, 한 장에 아이템 하나만 입고 있어 조합할 수 없습니다. 물병 그림은 팔 자세가 바뀌었습니다.

## 다시 만드는 방법 (권장)

이미지 생성 도구는 위치를 정확히 맞추는 일에 약합니다. 픽셀 편집 도구(Aseprite, Photoshop 등)에서 아래 순서로 작업해 주시길 부탁드립니다.

1. 기준 캐릭터(`char-m-workout-v2.png`, `char-f-workout-v3.png`)를 512×768 캔버스에 놓습니다. 크기와 위치를 절대 바꾸지 않습니다.
2. 그 위에 새 레이어를 만들고, 착용 그림 16종을 보면서 아이템을 **기준 캐릭터 몸 위에 직접** 그립니다.
3. 옷(상의·하의·신발)은 기본 옷을 **완전히 덮도록** 그립니다. 반팔 위에 후드를 그리면 반팔이 한 칸도 보이지 않아야 합니다.
4. 기준 캐릭터 레이어를 끄고 아이템 레이어만 투명 PNG로 내보냅니다.
5. 다시 켜서 겹쳐 보고, 착용 그림 16종과 같은 모습인지 확인합니다.

기본 몸 12장도 같은 방식으로, 기준 캐릭터를 부위별로 **잘라 나눠** 주세요. 새로 그리지 않고 나누기만 하면 겹쳤을 때 똑같아집니다.

## 다시 받을 것

| 묶음 | 장수 | 파일 이름 | 이번에 바뀌는 점 |
| --- | --- | --- | --- |
| 기본 몸 | 12 | `base-<m\|f>-<부위>.png` | 기준 캐릭터를 나눠서 만듦. 겹치면 기준 캐릭터와 똑같아야 함 |
| 아이템 레이어 | 32 | `item-<칸>-<이름>-<m\|f>.png` | 몸의 제자리에, 몸에 맞게 그림 |
| 아이콘 | 16 | `icon-<칸>-<이름>.png` | 받은 것 그대로 써도 됨. 다시 안 주셔도 됨 |

- 캔버스, 파일 이름, 칸 구분, 겹치는 순서는 앞선 요청서(v3)와 같습니다.
- 아이템 16종도 같습니다. 헤어밴드, 야구모자, 밀짚모자, 초록 리본, 흰 꽃, 뿔테 안경, 선글라스, 흰 집업, 초록 후드, 크림 후드, 회색 반바지, 줄무늬 긴바지, 진한 운동화, 초록 배낭, 물병, 왕관.

## 아이템별 주의할 점

| 아이템 | 지켜 주실 점 |
| --- | --- |
| 상의 3종 | 반팔과 팔 윗부분을 완전히 덮음. 소매 끝에서 손만 나옴 |
| 하의 2종 | 검은 바지를 완전히 덮음. 반바지는 무릎 아래가 다리(피부)로 보여야 하므로 그 부분은 피부색으로 칠해 덮음 |
| 운동화 | 흰 운동화 자리에 정확히 겹쳐 흰 신발이 보이지 않게 |
| 모자 2종 | 머리 윗부분을 덮어 머리카락이 모자 위로 삐져나오지 않게 |
| 헤어밴드, 리본, 꽃 | 머리 위에 얹기만. 머리카락은 그대로 보임 |
| 안경 2종 | 두 눈 위치에 정확히. 불투명하게 |
| 배낭 | 몸 뒤(`back` 칸)로 그려지므로 어깨 밖으로 보이는 부분만. 어깨끈은 `hand` 칸 그림 한 장 더, 또는 끈 없는 모양 |
| 물병 | 팔 자세를 바꾸지 않음. 오른손에 쥐었거나 손 옆에 붙은 모습. 캔버스 안에 들어오게 |
| 왕관 | 머리 꼭대기 가운데에. 머리카락 위에 얹힘 |

## 확인 방법

받은 뒤 아래를 확인합니다. 보내 주시기 전에 같은 방법으로 확인해 주시면 다시 오가는 일이 줄어듭니다.

- [ ] 기본 몸 6장을 겹치면 `char-m-workout-v2.png`와 똑같은가 (여성형은 `char-f-workout-v3.png`)
- [ ] 기본 몸 위에 아이템 하나를 겹치면 착용 그림 16종의 해당 그림과 같은 모습인가
- [ ] 상의 + 하의 + 신발 + 모자를 한꺼번에 겹쳐도 어색한 데가 없는가
- [ ] 아이템이 캔버스 밖으로 잘리지 않는가
- [ ] 반투명한 부분이 없는가 (가장자리 1~2px 부드럽게 처리는 괜찮음)
