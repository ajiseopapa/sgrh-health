움트다 의상 정리 + 새 직군 복장 v6

이번 ZIP은 v5에 덧붙이는 의상 수정 묶음입니다.
기본 몸 12장, 아이템 47종, 추가 소품은 v5 파일을 그대로 사용하세요.
기존 v5 묶음을 삭제하거나 덮어쓰지 않았습니다.

변경한 의상
- nurse / doctor / office / hoodie / scrub: 남녀 상의의 어깨·소매·목·허리 가장자리 정리
- 여성 office 하의: 기존 치마 안에 남아 있던 라임색·손 윤곽 조각 정리
- chef: 새 조리복. 흰 더블 단추 조리복, 체크 바지, 검은 조리화, 분리된 조리모
- worker: 새 작업복. 회녹색 점퍼·바지, 주머니·라임 반사띠, 작업화
- glasses → chef, vest → worker로 의상 선택 키를 교체합니다.
- workout은 v5 그대로입니다. 이번에 다시 만들지 않았습니다.

납품 파일
outfit/: 상의·하의·신발 7벌 x 남녀 = 42개 PNG, 조리모 남녀 2개 PNG (총 44개)
char/: 위 레이어를 실제 순서로 합성한 남녀 전신 14개 PNG
icon/: 조리복·작업복 선택용 아이콘 2개 PNG
source/: 편집 가능한 OpenRaster(.ora) 남녀 원본 2개 (각각 28개 레이어)
preview/: 전체 의상, 새 직군, v5/v6 확대 비교, 휴대폰 크기 미리보기
qa/: 검사 수치와 기존 47종 아이템 조합 미리보기
outfit-manifest.json: 의상 키·남녀 파일 경로·조리모 규칙

기존 5벌은 문제가 없는 하의·신발도 같은 이름 규칙으로 함께 넣었습니다.
기존 5벌의 하의·신발은 여성 office 하의를 제외하고 v5 픽셀 그대로입니다.
모든 기본/의상/전신 캔버스는 512x768, 원점 (0,0)입니다. 아이콘은 256x256입니다.
캐릭터의 얼굴·머리·몸·발 위치와 v5 기본 몸은 바꾸지 않았습니다.

소매와 외곽선 처리
기본 반팔의 라임색뿐 아니라 그 주변의 원래 검은 외곽선까지 의상 상의가 덮도록 했습니다.
시트에서 잘라 온 손·팔 윤곽이 새 소매에 남지 않도록 외곽을 정리했습니다.
새 외곽선은 끊어지지 않는 불투명 차콜 선으로 다시 둘렀습니다.
상의 14개와 조리모는 중간 알파 없이 0 또는 255입니다.
하의·신발을 그대로 가져온 부분의 기존 가장자리 처리는 보존했습니다.

앱에서 합성하는 순서
가방 → 뒷머리 → 몸
→ 기본 신발 → 의상 신발 (신발 아이템 선택 시 의상 신발 대신 아이템)
→ 기본 하의 → 의상 하의 (하의 아이템 선택 시 의상 하의 대신 아이템)
→ 기본 상의 → 의상 상의 (상의 아이템 선택 시 의상 상의 대신 아이템)
→ 안경 → 앞머리 → 머리 장식 → 모자 → 소품 → 특별.
기본 반팔을 빼지 않아도 됩니다. 이번 상의 레이어가 그 외곽선까지 덮습니다.

조리모
chef이고 모자 아이템이 없으면 outfit-hat-chef-m/f.png를 hat 위치에 합성합니다.
모자 아이템이 있으면 조리모를 생략하고 선택한 모자 하나만 합성합니다.
다른 의상에는 조리모를 표시하지 않습니다.

검수
- 상의 14개가 검사 대상 기본 반팔·차콜 외곽선을 완전히 덮음
- 상의 14개: 떨어진 알파 조각 0, 중간 알파 0, 바깥 3px의 비차콜 픽셀 0
- 실제 합성 결과와 char/ PNG의 픽셀 차이 0
- 조리모로 가려야 할 머리 윗부분의 미덮임 픽셀 0
- 조리모 기본/모자 아이템 대체, 상의·하의·신발 아이템 대체 합성 확인
- 기존 47종을 수정 의상과 합성한 점검 모음 포함
- 새 직군을 128x192, 48x72로 축소 확인
- 사원증: 수정·신규 7벌 모두 있음. 운동복은 기존대로 없음
실제 앱 연결이나 배포는 하지 않았고, 제공된 v5 파일로 합성 검수했습니다.
