움트다 옷 통그림 v8
최종 기준: 2026-11-20 움트다-옷-통그림-요청서.md

구성
- looks/: 사람과 옷이 함께 있는 전신 PNG 46장
  유니폼 7벌 × 남녀 = 14장, 옷 아이템 16벌 × 남녀 = 32장
- all-46.png: 46장 전체 모음. 각 캐릭터를 128×192로 표시
- catalog.json: 이름, 종류, 남녀 파일 경로, 사원증 여부
- qa/checks.json: 파일 규격, 머리 비교, 발바닥 높이, 사원증 색상 확인 결과
- qa/sha256.json: 46장 파일별 SHA-256

사용 방법
각 PNG 자체가 완성된 전신 그림입니다. 기본 몸이나 옷 레이어를 추가로 겹치지 않습니다.
512×768 투명 RGBA PNG이며 모든 파일의 원점은 0,0입니다.
파일명 m은 남성, f는 여성입니다. 유니폼에는 사원증이 있고 일반 옷에는 없습니다.
후드 집업 유니폼은 남녀 모두 라임 집업과 회색 바지입니다.
통그림 의상을 선택한 동안 기존 모자·장식 등을 숨기는 처리는 앱 측 적용 사항입니다.
이 묶음은 이미지 파일 납품이며 앱 변경·배포는 수행하지 않았습니다.
기존 v5 꾸미기 파일과 과거 버전은 이 ZIP에 섞지 않았습니다.

원본 정렬과 확인
제공된 기준 원본은 실제 256×384이므로 최근접 보간으로 정확히 2배 확대하여 사용했습니다.
44장은 목 위와 보존한 여성 뒷머리 영역에서 기준 픽셀 차이가 0입니다.
조리복 2장은 조리모가 덮는 부분만 예외이며 그 밖의 보존 영역 차이는 0입니다.
원본 머리에 포함된 가장자리 픽셀은 그대로 유지했습니다.
46장 모두 검은 신발 밑창의 마지막 행은 y=755로 기준과 같습니다.
모든 남녀 의상 쌍의 옷 부분을 2배 확대해 확인했고 전체 모음에서도 확인했습니다.
