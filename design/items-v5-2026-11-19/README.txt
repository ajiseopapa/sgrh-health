움트다 전체 아이템 — 두 시트 전체 범위 v5

전체 파일
1) ref-item-sheet.png: 아이템 47종 전체, 남녀 착용 레이어 94개
   모자 6 / 헤어 6 / 페이스 6 / 상의 7 / 하의 5 / 신발 5 / 가방·소품 7 / 특수 5.
   가방·소품과 특수 아이템은 실제 합성 슬롯에 따라 back/hand/effect로 나뉩니다.
2) ref-outfit-sheet.png: 의상 8세트 x 남녀 = 전신 PNG 16개
   운동복 / 간호복 / 의료진 가운 / 행정부 정장 / 후드 집업 / 스크럽 / 가운과 안경 / 셔츠 차림.
3) 의상 분리 레이어 50개: 위 의상의 남녀 상의·하의·신발, 가운과 안경의 안경 레이어.
4) 의상 시트 하단 소품 5종 x 남녀 = 10개: 청진기 / 사원증 / 클립보드 / 펜 / 마스크.
5) 기본 레이어 12개, 상점 아이콘 52개(47종 + 추가 소품 5종).
6) 남녀 편집 원본 OpenRaster(.ora) 2개, 각각 83개 레이어.

파일 위치
base/: 기준 캐릭터의 6개 기본 레이어 x 남녀
item/: 첫 시트 47종의 남녀 착용 레이어 (512x768 RGBA PNG)
icon/: 상점 아이콘 (256x256 RGBA PNG)
char/: 의상 16개 전신 PNG (512x768)
outfit-layer/: 의상 전신을 구성하는 개별 착용 레이어 (512x768)
extra/: 의상 시트 하단 소품의 착용 레이어 (512x768)
source/: 편집 가능한 .ora 원본 (Krita/GIMP 등으로 열기)
preview/: 분류별 남녀 착용 모음과 의상 16개 모음
qa/: 파일 검사 수치, 47종을 다른 슬롯과 함께 합성한 점검 모음
catalog.csv / catalog.json: 두 시트와 파일 이름을 대응하는 전체 목록
preview.html: 47종과 의상 8세트, 추가 소품을 선택하는 오프라인 미리보기

미리보기 사용
ZIP 압축을 먼저 풀고 preview.html을 여세요.
의상 세트를 고른 후 슬롯별 아이템을 선택합니다. 남녀 캐릭터를 동시에 표시합니다.
상의/하의/신발을 선택하면 해당 의상 세트의 같은 부위를 교체합니다.
PNG는 캐릭터 위치에 맞춰져 있으므로 투명 여백을 자르지 말고 원점(0,0)에 겹칩니다.

기준 캐릭터
남성 char-m-workout-v2.png / 여성 char-f-workout-v3.png.
제공된 기준 원본의 실제 크기는 256x384입니다.
비율과 원점을 유지하여 최근접 방식으로 정확히 2배 확대한 512x768로 작업했습니다.
기본 6장을 합치면 이 기준 이미지와 보이는 픽셀 차이 0입니다.
얼굴, 머리, 몸 크기, 발 위치를 아이템마다 다시 생성하지 않았습니다.
기본 레이어는 최신 재요청서에 따라 원본을 나눈 파일입니다. 가려진 맨몸을 새로 그린 파일은 아닙니다.

착용 방식
기본 운동복 6장을 그대로 합성하고, 같은 칸의 아이템을 위에 겹칩니다.
상의를 교체하면 원래 라임색 반팔을 덮습니다.
반바지 레이어에는 원래 긴바지를 가릴 피부색 다리도 포함되어 있습니다.
배낭은 끈 없는 형태로 back에서 몸 뒤에 합성합니다. 날개도 back입니다.
크로스백·복주머니·힙색·수건·물병·스마트워치는 hand에서 위에 합성합니다.
물병과 추가 소품은 원래 팔 자세를 유지하도록 손 옆 또는 원래 몸 위치에 배치했습니다.
하이탑의 발목 부분은 긴바지에 가려집니다. 반바지와 조합하면 발목 부분이 보입니다.
운동복에는 사원증이 없고, 나머지 의상에는 사원증이 있습니다.

합성 순서
아이템 back → 기본 hair-back → 기본 body
→ 기본 shoes → 선택한 의상 shoes 또는 아이템 shoes
→ 기본 bottom → 선택한 의상 bottom 또는 아이템 bottom
→ 기본 top → 선택한 의상 top 또는 아이템 top
→ 아이템 face → 기본 hair-front → 아이템 hair → 아이템 hat → 아이템 hand → 아이템 effect.
의상 부분을 선택했을 때도 기본 부위를 받쳐 두세요. 기존 몸을 덮는 착용 방식입니다.

검수 범위
- 아이템 47종의 남녀 PNG 94개와 의상 전신 16개, 추가 소품 남녀 10개 존재 확인
- 기본/착용/의상/추가 소품 모두 512x768 RGBA, 아이콘은 256x256
- 남녀 기본 레이어 재합성 픽셀 차이 0
- 아이템 및 의상 상의 밖으로 남는 원래 불투명 라임색 반팔 픽셀 0
- 캔버스 안의 배치, 분류별 착용 및 여러 슬롯 조합 미리보기 확인
- 편집 원본의 레이어와 ZIP 파일 무결성 확인
파일 합성으로 검사했으며, 실제 앱에 연결하거나 배포한 것은 아닙니다.

제작 방식
승인된 착용 그림과 의상 시트에서 옷 부분을 분리하고 고정된 기준 좌표에 맞춰 편집했습니다.
추가 아이템은 시트의 색과 형태를 참고해 픽셀 단위로 그렸습니다.
기존 원본 가장자리 처리는 기본 레이어에서 보존했습니다.
정원·나무·운동 배지 등, 이번에 지정하신 두 시트에 없는 별도 이미지 묶음은 포함하지 않았습니다.
