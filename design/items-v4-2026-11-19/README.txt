움트다 캐릭터 아이템 — 재요청서 대응 v4

구성
- base/: 기본 레이어 12개 PNG (남녀 각각 6개)
- item/: 아이템 착용 레이어 32개 PNG (16종 x 남녀)
- char/: 최신 기준 캐릭터를 512x768로 정규화한 비교용 PNG 2개
- source/: 남녀 편집 원본 2개, OpenRaster(.ora). Krita/GIMP 등에서 레이어로 열 수 있습니다.
- preview/: 16종 남녀 개별 합성, 전체 모음, 여러 슬롯 동시 합성
- qa/: 기본 재합성 PNG, 남녀 각각 18가지 조합, 검사 수치

기준
남성 char-m-workout-v2.png, 여성 char-f-workout-v3.png.
제공 원본의 실제 크기는 256x384입니다. 같은 좌표 원점과 비율을 유지해
최근접 보간으로 정확히 2배 확대하여 512x768을 기준 캔버스로 삼았습니다.
얼굴/몸/발을 항목마다 다시 생성하지 않았습니다.

기본 레이어
기준 캐릭터 픽셀을 겹치지 않는 여섯 부분으로 나눴습니다.
재합성한 결과는 남녀 모두 원본을 정규화한 이미지와 보이는 픽셀 차이 0입니다.
이번 재요청서의 '새로 그리지 않고 나누기만' 조건에 따라 가려진 맨몸은 복원하지 않았습니다.
따라서 기본 몸만 표시하는 용도가 아닌, 기본 6개를 합성하고 슬롯 아이템을 겹치는 용도입니다.

아이템
승인한 착용 그림에서 의상/모자/장식을 분리하고 고정된 기준 몸에 맞췄습니다.
안경/헤어밴드/물병/배낭은 기준 좌표에서 픽셀 편집했습니다.
상의 3종은 기존 반팔 위에, 하의 2종은 기존 긴바지 위에, 운동화는 기존 흰 신발 위에 겹칩니다.
회색 반바지 레이어에는 기존 긴바지를 가릴 피부색 다리도 포함되어 있습니다.
배낭은 back 슬롯에서 몸 뒤에 배치하는 끈 없는 형태입니다.
물병은 기존 팔 자세를 유지하도록 손 옆에 배치했습니다.
안경의 렌즈 구멍은 완전 투명, 프레임은 완전 불투명입니다.
나머지 아이템도 중간 투명도 없이 알파 0 또는 255입니다.
기준 캐릭터의 기존 가장자리 처리는 원본 그대로입니다.

합성 순서
아이템 back → 기본 hair-back → 기본 body → 기본 shoes → 아이템 shoes
→ 기본 bottom → 아이템 bottom → 기본 top → 아이템 top → 아이템 face
→ 기본 hair-front → 아이템 hair → 아이템 hat → 아이템 hand → 아이템 effect

검사
- 기본 레이어 재합성: 남녀 보이는 픽셀 차이 0
- 기본/아이템 PNG: 모두 512x768
- 아이템 중간 알파: 0개
- 3종 상의 밖으로 남는 원본의 불투명 라임색 반팔 픽셀: 남녀 모두 0
- 32개 아이템은 모두 캔버스 안에 위치
- 파일 합성으로 16종 각각, 남녀 18조합씩 확인
앱에 배포하거나 앱 안에서 실행하는 검증은 하지 않았습니다.

아이콘은 재요청서에서 재납품 생략을 허용했으므로 포함하지 않았습니다.
사원증 변경과 기존 정원/배지 등의 다른 묶음은 이번 재요청 범위에 포함하지 않았습니다.
